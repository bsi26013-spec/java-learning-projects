# 01 - メニュー注文システム

## 概要
メニューから商品を選んで数量を入力し、合計金額（税込10%）を計算するコンソールアプリケーション。

## 機能
- **メニュー選択**：3種類の商品（ハンバーガー、カレー、サラダ）から選択
- **個数入力**：注文個数を指定
- **自動計算**：
  - 小計（単価 × 個数）
  - 消費税（10%）
  - 合計金額

## 使い方
```bash
cd 01/src
javac Main.java
java Main
```

実行後、メニュー番号と個数を入力すると、詳細な支払い額が表示されます。

## 技術ポイント
- `switch` 式（Java 14+）を使用した条件分岐
- `Scanner` クラスでのユーザー入力処理
- 四則演算での料金計算
