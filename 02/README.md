# 02 - 映画館座席予約システム

## 概要
映画館の座席表を表示し、ユーザーが指定した座席を予約するコンソールアプリケーション。

座席は `A-3` のような形式で入力し、空席の場合のみ予約済みに変更します。

## 機能
- **座席表表示**：10列 × 8座席の座席状態を表示
- **座席番号表示**：上部に 1〜8 の座席番号を表示
- **座席入力**：`A-3` 形式で予約したい座席を指定
- **予約判定**：
  - 空席の場合は予約済みに変更
  - 予約済みの場合はメッセージを表示

## 使い方
```bash
cd 02/src
javac Main.java
java Main
```

実行後、座席表を確認して `A-3` のように座席を入力すると、予約結果と更新後の座席表が表示されます。

## 技術ポイント
- 2次元配列 `boolean[][]` を使用した座席管理
- `true` / `false` による予約状態の判定
- 2重ループでの座席表表示
- `Scanner` クラスでのユーザー入力処理
- 文字コード計算による `A〜J` の列番号変換
