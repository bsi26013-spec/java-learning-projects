# 03 - クラス成績集計アプリ

## 概要
生徒ごとの3教科の点数を表示し、合計点・平均点・合格判定を行うコンソールアプリケーション。

最後に、教科ごとの平均点も計算して表示します。

## 機能
- **成績表表示**：生徒ごとに国語・数学・英語の点数を表示
- **生徒別集計**：
  - 3教科の合計点を計算
  - 3教科の平均点を計算
- **合格判定**：
  - 平均点が60点以上の場合は合格
  - 平均点が60点未満の場合は不合格
- **教科別平均**：
  - 国語、数学、英語それぞれの平均点を計算

## 使い方
```bash
cd 03/src
javac Main.java
java Main
```

実行すると、生徒ごとの成績表と教科別平均点が表示されます。

## 実行例
```text
===== クラス成績表 =====

名前    国語 数学 英語 合計 平均 判定
田中     80   70   90   240  80  合格
佐藤     55   60   50   165  55  不合格
鈴木     90   85   95   270  90  合格

===== 教科別平均 =====

国語の平均点: 75点
数学の平均点: 71点
英語の平均点: 78点
```

## 技術ポイント
- `String[]` を使用した生徒名・教科名の管理
- `int[][]` を使用した点数管理
- 2重ループでの成績表表示
- 2重ループでの教科別平均点の計算
- `if` 文を使用した合格/不合格の判定
- 整数同士の割り算による平均点計算
